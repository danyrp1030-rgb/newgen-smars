**What is SMARS?**

-SMARS (Screwless Modular Assemblable Robotic System) are, Netherlands based, open-source beginner friendly robots that are 3-D printed, simple, and affordable.

-Powered by simple parts such as Arduinos, motors, motor shields, 9V batteries, and 3-D printed parts

-The different features of the robots are connected through simple attachments and screwless assembly

-More information can be found on SMARS's very own [Github](https://github.com/kevinmcaleer/smars) run by Kevin McAleer
